# Admin Dashboard
This is a comprehensive admin dashboard application built with React, featuring a professional UI using Ant Design (antd), and powered by TanStack Query (formerly React Query) for highly efficient data fetching, caching, and state management.

# Features
- Secure and scalable admin interface  
- Dynamic data tables with sorting, filtering, and pagination  
- API-driven architecture with caching and background updates  
- Smooth animations and transitions  
- Skeleton loaders for better perceived performance  
- Lottie animations for empty states and user feedback  
- Toast notifications for user actions  
- Fully responsive layout  
- Clean and maintainable component structure  


# Tech Stack
- Framework: React.js  
- UI Components: Ant Design  
- Styling: Tailwind CSS  
- Animations: Framer Motion  
- Data Fetching: TanStack Query (React Query)  
- Loaders: React Loading Skeleton  
- Animations (JSON): Lottie  
- Notifications: React Hot Toast
